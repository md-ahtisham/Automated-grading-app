# 🎓 Welcome to "Automated Grading App" — AI-Powered Answer Evaluation System 📑

## 📚 Introduction

Manual grading is time-consuming and subjective. This project solves that by using AI to automatically grade student responses based on model answers — delivering instant "Yes"/"No" results with a clean, privacy-conscious workflow.

## 🚀 Live App

👉 [Click to Open the App](https://automated-grading-app-mbmhjeu7pndkzewwdmpa9v.streamlit.app/)

---


### Why AI Grading?

This app leverages generative models to assess short and long answers submitted by students. By parsing PDFs and using an intelligent reasoning engine, it streamlines the grading process for educators, saving time and improving consistency.

### Business Value

- **Efficiency Boost**: Grade entire answer sheets in seconds  
- **Consistency**: AI eliminates human bias  
- **Instructor Productivity**: Focus on teaching, not marking  
- **Scalable**: Handle large volumes effortlessly  
- **Simple UI**: No training required for faculty  

---

## 🌟 Features

- **PDF Upload**: Upload a PDF file containing question-answer pairs
- **AI-Based Answer Evaluation**: Uses Gemini Pro to evaluate correctness
- **Structured Output**: Shows "Yes" or "No" for each response
- **Streamlit UI**: User-friendly and fast to deploy
- **Auto Parsing**: Extracts questions and answers from text
- **Lightweight & Fast**: Built for quick assessments

---

## 🛠️ Technologies Used

- **Streamlit** – Web app framework  
- **Gemini Pro (Google Generative AI)** – Answer evaluation  
- **PyMuPDF (fitz)** – PDF parsing  
- **Python 3.10+** – Programming language  
- **OpenAI-style prompting** – For binary classification

---

## 📋 Prerequisites

- Python 3.10 or higher  
- Google API Key (Gemini)
